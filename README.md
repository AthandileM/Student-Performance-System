Student Performance System:
A Java based Student Performance System that uses OOP to store and calculate a student's academic performanc.
Features:
Stores Student information such as the name, age and course.
Stores multiple student marks using an ArrayList.
Finds the highest mark.
Finds the lowest mark.
Determines if a student passed or failed.
Displays a student performance report.
OOP concepts used:
Classes and objects: A Student class is used to represent a student. 
Encapsulation: Student information and marks are stored using private fields. 
Constructors: A constructor is used to initialise the students details.
Methods: Separate methods are used to add marks and calculate performance results.
ArrayList:An ArrayList<Integer> is used to store the students marks.
Technologies used:
Java
NetBeans
Project Structure:
Student.java: Contains the Student class, student information, marks and performance related methods.
StudentPerformanceSystem.java:Contains the main method and runs the program.
Purpose:
This project was created to practise Java programming and Object Oriented Programming concepts while building a simple system that can process and display student performance. It addresses the simple problem of manually calculating and evaluating a student's total, average, highest and lowest marks, as well as their overall result.
